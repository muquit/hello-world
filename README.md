# Introduction

A test project for testing homebrew formulae

# How to install using brew

Homebrew maps muquit/hello-world to https://github.com/muquit/hello-world 
and looks for formulas in the Formula/ directory automatically.

```
brew tap muquit/hello-world https://github.com/muquit/hello-world
brew install hello-world
```

or in one command:

```
brew install muquit/hello-world/hello-world
```
