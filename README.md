# Introduction

A test project for testing homebrew formulae created by go-xbuild-go

# Compile
```bash
make
```

# How to install using brew

## First time install

```
brew tap muquit/hello-world https://github.com/muquit/hello-world.git
brew install muquit/hello-world/hello-world
```

## Update
```
brew update
brew upgrade muquit/hello-world/hello-world
```

# Uninstall
```
brew uninstall hello-world
```

# Remove the tap
```
brew untap muquit/hello-world
```
